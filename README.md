# SolarSystem – Unser Sonnensystem 🪐

Eine interaktive Website, mit der Kinder das Sonnensystem entdecken können.

**[Im Browser öffnen](https://kungfubrot.github.io/SolarSystem/)**

## Starten

Online über den Link oben, oder lokal einfach `index.html` im Browser öffnen (Doppelklick). Es wird nichts installiert.

## Was man machen kann

- **Ganzes Sonnensystem ansehen** und von dort aus jeden Planeten anklicken
- **Planeten anklicken** → eine kleine 🚀 Rakete fliegt hin (beim ersten Mal von der Erde aus), die Ansicht zoomt auf den Planeten, und die Info-Karte erscheint mit kindgerechten Fakten, „Wusstest du?“ und Größenvergleich mit der Erde
- **🔭 Zum ganzen Sonnensystem** → Karte schließen und zurück zur Übersicht
- **🔊 Vorlesen** → der Browser liest die Infos auf Deutsch vor
- **Zoomen** mit Mausrad, zwei Fingern (Touch) oder den Knöpfen `+` / `−`
- **Verschieben** durch Ziehen mit Maus oder Finger
- **Zeit** anhalten und schneller/langsamer laufen lassen (🐢 … 🚀)
- **📏 Echte Größen** → alle Planeten in echtem Größenverhältnis neben der riesigen Sonne

Tastatur: `+` / `−` zoomen, `Leertaste` Pause, `Esc` oder `0` zurück zur Übersicht.

## Dateien

- `index.html` – Seitenaufbau
- `style.css` – Aussehen
- `js/data.js` – alle Texte und Zahlen zu Sonne, Planeten und Mond (hier kann man Fakten ergänzen)
- `js/app.js` – Zeichnen, Zoomen, Rakete, Bedienung
